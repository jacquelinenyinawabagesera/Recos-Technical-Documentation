    Integrations Guide

    This comprehensive guide provides step-by-step instructions for integrating your platform with Odoo, Google Calendar/Meet, AssemblyAI, and Gemini (Google AI).
    It covers setup, configuration, API usage, troubleshooting, and best practices to ensure smooth implementation and secure operations.

    Odoo Integration

    Purpose:
    Connect to Odoo for managing jobs, candidates, and company data.

    1. Setup

    • Odoo Instance URL: e.g., https://your-odoo-instance.com
    • API Key: Generate in Odoo (Settings → API Keys)
    • Permissions: Ensure your user has access to jobs, candidates, and companies

    2. Store Credentials (in .env)

    ODOO_URL=https://your-odoo-instance.com
ODOO_EMAIL=your@email.com
ODOO_API_KEY=yourapikey

    3. Connect via API

    import requests

url = f"{ODOO_URL}/api/jobs"
headers = {"Authorization": f"Bearer {ODOO_API_KEY}"}
response = requests.get(url, headers=headers)
print(response.json())

    4. Common API Endpoints

    • GET /odoo/jobs — Fetch jobs
    • GET /odoo/candidates — Fetch candidates

    5. Troubleshooting

    Issue Solution
    401 Unauthorized Check API key and user permissions
    Connection Error Ensure Odoo server is running and accessible
    Timeouts Optimize endpoints, use pagination if available

    6. Best Practices

    • Never log or expose API keys
    • Use environment variables for sensitive data
    • Handle rate limiting and implement retry logic

    Google Calendar and Google Meet Integration

    Purpose:
    Automate interview scheduling and generate secure Meet links.

    1. Google Cloud Project Setup

    • Open Google Cloud Console
    • Create a new project (e.g., “Recruitment Platform”)

    2. Enable APIs

    • Google Calendar API
    • Google People API (for attendee profiles)
    • Google Meet is enabled via Calendar events

    3. OAuth 2.0 Client Credentials

    • Go to APIs & Services → Credentials
    • Click Create Credentials → OAuth Client ID
    • Choose Web application and set your redirect URI
      (e.g., https://your-domain.com/api/auth/google/callback/)
    • Download credentials.json and store securely
    • Add client ID and secret to .env

    4. OAuth Flow (Python Example)

    from google_auth_oauthlib.flow import Flow

flow = Flow.from_client_secrets_file(
    'credentials.json',
    scopes=['https://www.googleapis.com/auth/calendar'],
    redirect_uri='https://your-domain.com/api/auth/google/callback/'
)
authorization_url, state = flow.authorization_url(access_type='offline', prompt='consent')

    5. Create Events and Meet Links

    event = {
    'summary': 'Interview',
    'start': {'dateTime': '2025-10-02T10:00:00-07:00', 'timeZone': 'America/Los_Angeles'},
    'end': {'dateTime': '2025-10-02T11:00:00-07:00', 'timeZone': 'America/Los_Angeles'},
    'attendees': [{'email': 'candidate@example.com'}],
    'conferenceData': {'createRequest': {'requestId': 'sample123'}}
}
created_event = calendar_service.events().insert(
    calendarId='primary',
    body=event,
    conferenceDataVersion=1
).execute()
meet_link = created_event['hangoutLink']

    6. Example API Endpoints

    • POST /calendar/events — Create event and Meet link
    • GET /calendar/meets — List Meet links

    7. Troubleshooting

    Issue Solution
    Redirect URI mismatch Ensure URI matches in Google Console and your app
    Missing conferenceData Add conferenceDataVersion=1 when creating events
    Token expired Implement token refresh logic
    Invalid credentials Check your credentials.json and .env

    8. Security and Best Practices

    • Never expose credentials.json
    • Encrypt and securely store tokens
    • Use HTTPS for all OAuth flows

    9. Error Handling

    • Log errors and monitor (e.g., Sentry)
    • Always handle exceptions for network/API calls

    AssemblyAI Integration

    Purpose:
    Transcribe interviews in real time and generate text transcripts.

    1. AssemblyAI Setup

    • Register at AssemblyAI
    • Get your API key from the dashboard

    2. Store API Key (in .env)

    ASSEMBLYAI_API_KEY=your_api_key

    3. Upload Audio and Start Transcription

    import requests

headers = {'authorization': ASSEMBLYAI_API_KEY}
response = requests.post('https://api.assemblyai.com/v2/upload', files={'file': open('audio.mp3', 'rb')}, headers=headers)
audio_url = response.json()['upload_url']

transcript_response = requests.post(
    'https://api.assemblyai.com/v2/transcript',
    json={'audio_url': audio_url},
    headers=headers
)
transcript_id = transcript_response.json()['id']

    4. Poll for Transcription Completion

    import time
while True:
    res = requests.get(f'https://api.assemblyai.com/v2/transcript/{transcript_id}', headers=headers)
    status = res.json()['status']
    if status == 'completed': break
    elif status == 'failed': raise Exception('Transcription failed')
    time.sleep(5)
transcript_text = res.json()['text']

    5. Troubleshooting

    Issue Solution
    Large files Use chunked upload for >100MB
    API limits Monitor and handle rate limiting
    Audio format Use standard formats (mp3, wav, etc.)

    6. Best Practices

    • Never expose your API key
    • Delete audio files after processing

    Gemini Integration (AI Reports)

    Purpose:
    Analyze interviews, extract sentiment, and generate candidate recommendations using Google Gemini.

    1. Gemini API Setup

    • Sign up and enable Gemini API on Google AI Platform
    • Obtain API key and set quotas

    2. Store API Key (in .env)

    GEMINI_API_KEY=your_api_key

    3. Send Data for AI Analysis

    import requests

headers = {"Authorization": f"Bearer {GEMINI_API_KEY}"}
data = {"interview_text": transcript_text, "candidate_profile": {...}}
response = requests.post("https://gemini.googleapis.com/v1/analyze", json=data, headers=headers)
report = response.json()

    4. Handle Response

    • Parse report for recommendations, strengths, gaps, and scores
    • Display results in your dashboard

    5. Troubleshooting

    Issue Solution
    API errors Validate data format and authentication
    Quota Monitor usage, request more if needed
    Latency Show loading indicator for slow reports

    6. Best Practices

    • Never expose your Gemini API key
    • Validate and sanitize all data sent to Gemini

    General Troubleshooting and Best Practices

    • Use .env for all secrets—never commit credentials
    • Enforce HTTPS for all APIs and OAuth flows
    • Monitor logs (Django, Vercel, Heroku, Sentry) for errors and usage
    • Handle errors gracefully and inform users of next steps
    • Keep API libraries updated for security and compatibility
    • Test integrations with sandbox/test accounts before production
