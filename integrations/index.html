    Odoo Integration

    Purpose in Recos:
    Odoo integration is central to Recos.
    It enables recruiters to connect their Odoo account and manage jobs, candidates, and company data directly from the platform.
    All recruiter authentication, job and candidate data, and company information are trusted and synced from Odoo, ensuring accuracy and up-to-date records.

    Where is it used?

    • Authenticating recruiter accounts (via Odoo credentials)
    • Fetching jobs, companies, and candidate profiles
    • Keeping candidate/job data synced between Odoo and Recos
    
### Setup

- Obtain your Odoo Instance URL (e.g., `https://your-odoo-instance.com`)
- Generate an API Key in Odoo (Settings → API Keys)

    ODOO_URL=https://your-odoo-instance.com ODOO_EMAIL=your@email.com ODOO_API_KEY=yourapikey

    
### Example: Connecting via API

```python
import requests

url = f"{ODOO_URL}/api/jobs"
headers = {"Authorization": f"Bearer {ODOO_API_KEY}"}
response = requests.get(url, headers=headers)
print(response.json())

    Common API Endpoints

    • GET /odoo/jobs — Fetch jobs
    • GET /odoo/candidates — Fetch candidates

    Google Calendar & Google Meet Integration

    Purpose in Recos:
    This integration automates interview scheduling and provides secure Google Meet links for each interview.
    It is a core part of the interview process, allowing recruiters to:

    • Schedule candidate interviews
    • Send out invites to candidates
    • Ensure seamless virtual meetings

    Where is it used?

    • Scheduling interviews with candidates
    • Generating and sending Google Meet links via calendar invites
    • Storing interview event details in recruiters' calendars

    Google Cloud Project Setup

    • Open Google Cloud Console
    • Create a new project (e.g., “Recruitment Platform”)

    Enable APIs

    • Google Calendar API
    • Google Meet is enabled by default when creating Calendar events

    OAuth 2.0 Client Credentials

    • Go to APIs & Services → Credentials
    • Create OAuth Client ID for Web Application
    • Set your redirect URI (e.g., https://your-domain.com/api/auth/google/callback/)
    • Download credentials.json and store securely
    • Add client ID and secret to .env

    OAuth Flow Example (Python)

    from google_auth_oauthlib.flow import Flow

flow = Flow.from_client_secrets_file(
    'credentials.json',
    scopes=['https://www.googleapis.com/auth/calendar'],
    redirect_uri='https://your-domain.com/api/auth/google/callback/'
)
authorization_url, state = flow.authorization_url(access_type='offline', prompt='consent')

    Create Calendar Events & Meet Links

    event = {
    'summary': 'Interview',
    'start': {'dateTime': '2025-10-02T10:00:00-07:00', 'timeZone': 'America/Los_Angeles'},
    'end': {'dateTime': '2025-10-02T11:00:00-07:00', 'timeZone': 'America/Los_Angeles'},
    'attendees': [{'email': 'candidate@example.com'}],
    'conferenceData': {'createRequest': {'requestId': 'sample123'}}
}
created_event = calendar_service.events().insert(
    calendarId='primary',
    body=event,
    conferenceDataVersion=1
).execute()
meet_link = created_event['hangoutLink']

    API Endpoints in Recos

    • POST /calendar/events — Create event and Meet link
    • GET /calendar/meets — List Meet links

    Security & Best Practices

    • Never expose or commit credentials.json
    • Encrypt and securely store tokens
    • Only request minimum necessary OAuth scopes

    Google Speech-to-Text Integration

    Purpose in Recos:
    This integration transcribes interviews in real time, converting audio from Google Meet calls into text.
    Transcriptions are used for further AI analysis, reporting, and generating interview insights.

    Where is it used?

    • During the interview: All recruiter and candidate speech is transcribed.
    • After the interview: Transcripts are sent to Gemini AI for analysis and report generation.

    Setup

    • Enable Google Cloud Speech-to-Text API in your Google Cloud project
    • Obtain API key and store in .env

    Store API Key (.env)

    GOOGLE_SPEECH_TO_TEXT_API_KEY=your_api_key

    Transcribe Interview Audio (Python Example)

    import requests

audio_file = open('interview_audio.wav', 'rb')
headers = {"Authorization": f"Bearer {GOOGLE_SPEECH_TO_TEXT_API_KEY}"}
response = requests.post(
    "https://speech.googleapis.com/v1/speech:recognize",
    headers=headers,
    data=audio_file
)
transcript_text = response.json()['results'][0]['alternatives'][0]['transcript']

    Gemini Integration (AI Reports & Question Generation)

    Purpose in Recos:
    Gemini AI integration powers two essential features in the Recos platform:

    • Interview Add-on (Question Generation):
      Gemini analyzes candidate CVs and job descriptions to dynamically generate tailored interview questions and follow-up prompts during the interview.

    • AI Reports:
      After the interview, Gemini produces a detailed report that analyzes the transcript and candidate performance. This includes sentiment analysis, skill demonstration, identification of strengths and gaps, and final recommendations for the recruiter.

    Where is it used?

    • Pre-interview: Generating interview questions based on job requirements and candidate profiles.
    • During interview: Adapting questions and probing deeper into candidate responses in real time.
    • Post-interview: Generating AI-powered reports for recruiter decision support.

    Setup

    • Enable Gemini API on Google AI Platform
    • Obtain API key and set quotas

    Store API Key (.env)

    GEMINI_API_KEY=your_api_key

    Example: Sending Data to Gemini for Analysis

    import requests

headers = {"Authorization": f"Bearer {GEMINI_API_KEY}"}
data = {
    "interview_text": transcript_text, 
    "candidate_profile": {...},
    "job_description": {...}
}
response = requests.post("https://gemini.googleapis.com/v1/analyze", json=data, headers=headers)
report = response.json()
